
# Database SQL Internship Project

## Project Name
Student Management System

## Description
This project demonstrates SQL queries and joins using a Student Management System database.

## Database Tables
1. Students
2. Courses
3. Enrollments
4. Payments

## SQL Concepts Used
- CREATE TABLE
- INSERT INTO
- INNER JOIN
- GROUP BY
- SUM()

## Queries Included
1. Display student names and course names.
2. Display student names and payment amounts.
3. Display each student's total payment amount.

## Tools Used
- SQL
- GitHub

## How to Run
1. Open the queries.sql file.
2. Copy the SQL code.
3. Execute it in an SQL database environment.
4. View the query results.
